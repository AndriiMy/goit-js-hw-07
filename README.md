JavaScript Homework 07 Template

Стартові файли для виконання домашнього завдання №7 курсу JavaScript.

Репозиторій містить готову HTML-розмітку, стилі та підключені JavaScript-файли для кожного завдання.

Як розпочати роботу

Натисни Use this template.
Обери Create a new repository.
Назви свій репозиторій goit-js-hw-07.
Зроби репозиторій публічним.
Склонуй створений репозиторій на комп’ютер.
Відкрий проєкт у редакторі коду.
Виконуй кожне завдання у відповідному JavaScript-файлі.

Важливо

Не змінюй готову HTML-розмітку завдань.
Виконуй завдання у файлах js/task-1.js — js/task-5.js.
Додавай стилі відповідно до макетів.
Перевіряй, щоб у консолі не було помилок і попереджень.
Назва студентського репозиторію має бути goit-js-hw-07.
